# Playbook: pickup

Pick when: another agent's, branch's or session's work is to be taken
over, or the last reply is to be rechecked.

1. Read the trail, bulk reads delegated at quick level: transcript,
   branch, worktree, ledger. Only this workspace's sessions. Evidence:
   a reduced timeline.
2. Reconstruct state per lead-howto/holds.md: git log and diff
   against base, open todos, decisions made. The trail is input; do
   not re-derive it.
3. Diff done vs pending against the plan. Name the resume point. No
   redone repro or finished work.
   Recheck of the last reply: one item per numbered claim, each
   re-verified once on its surface; say what changed. No blind repeat.
4. Route the remainder to its playbook: continue, ship, ratify or
   override a conclusion, or post-mortem a failed run.
5. prove-it-works, build level: each inherited claim on the real
   artifact. A prior self-report is not proof.

Report: where the prior agent stopped, inherited vs redone, the
resume point, the routed playbook.

Ends on: a resume point and a routed item; the routed playbook owns
the rest.

Escalate to the owner when the trail and the tree disagree.
