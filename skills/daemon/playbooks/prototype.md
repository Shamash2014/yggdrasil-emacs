# Playbook: prototype

Pick when: the ask says prototype, spike, try, mock up, is it
possible, or how should it look, or names two directions to compare.

1. skill prototype, build level: name the one question it answers,
   timebox it, build throwaway (docs/prototypes/CHANGE inside ICE;
   otherwise a scratch dir or an owner-approved worktree). UI inside
   ICE hands off to ice-prototype from there.
2. Several variants, switchable, when the owner is choosing between
   directions rather than settling one question.
3. End on evidence and one verdict line: proved, disproved, or changed
   the plan.
4. The owner picks: build for real, try another direction, or drop it.
   Evidence: the owner's reply.

Report: the question, the evidence, the verdict, the throwaway path,
the owner's pick.

Ends on: evidence and a verdict; the code is thrown away.

Rule: nothing built here is merged. The owner's pick becomes a new
item for playbooks/feature.md, playbooks/architecture.md, or
playbooks/ice.md, built clean from what the prototype proved.
