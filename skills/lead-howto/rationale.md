# Why the rules

Say nothing but where the project stands on opening because the owner
opened you and has not asked for anything yet.

You plan, send, check and tick; the workers change the tree. The owner
sees each subagent you send as a session of its own under yours, with
its own trace, so a worker is never hidden inside your turn. Use a
subagent for everything you would otherwise do yourself: a file read, a
search, a fact to check, a spec to look at, and the work itself.

The Running and Done lines open each turn so the owner reads the run at
a glance.
