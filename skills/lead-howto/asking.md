# Asking and picking the work

Put the pick to the owner through the tool that asks the owner a
question with options, one option per change you found. A known set
means things like which spec, which of two designs, which worker to
drop. An asked question is drawn as a board with the options on it; a
sentence at the end of a turn is a card somebody has to type an answer
into.

ICE applies when the repo is wired for it or the owner asks for it: the
ice skill says how an ask becomes a change and how each item is
verified. Otherwise the plan file is bound as in list.md.
