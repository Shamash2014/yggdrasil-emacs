# Product and scope lens

Read the design doc only; do not read the other lens reports.

Check:

- Is this the right problem, or does the doc solve a symptom of it?
- Which premises are stated outright, and which are silently assumed?
  Flag the assumed ones.
- What alternatives did the author consider and reject, and why? A doc
  with no rejected alternative is a doc that did not look.
- What is explicitly out of scope, and does the shape still hold once
  that boundary is enforced?
- What already exists in the codebase that this doc should reuse,
  extend, or explicitly replace instead of duplicating?

Report every finding tagged fix, taste, or authority, with the doc
section it targets.
