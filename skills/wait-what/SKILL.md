Wait — I do not understand where you have got to here.

Re-pitch it. A line of context first: what you were doing, what you
found. Then the thing again.

ASD-STE100 Simplified Technical English: one idea per sentence, short,
active, the same word for the same thing.

Use the names the code and the records already use — the project's
context file where there is one, the repository's instruction file
otherwise. A new name gets one line saying what it is.

A decision: the decision, the reason, what it rules out. A finding:
what you saw, where, what it means for the work.

Nothing new, no apology, no restating the turn. Same message, landed.
